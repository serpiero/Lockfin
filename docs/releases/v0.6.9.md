# Lockfin Companion 0.6.9 / Flipper app 0.26 — unreleased

Release candidate validation and remaining manual checks are recorded below.

## Changes

- New and password-changed vaults use 600,000 PBKDF2-HMAC-SHA256 iterations. The reader accepts costs through 2,000,000.
- Existing LMV1/LMV2 vaults remain readable because their iteration count is read from the authenticated header. The 40-byte header, format and GCM AAD are unchanged.
- Re-encrypt an older vault with `python vault.py passwd <vault.lmv>` or **Manage → Change vault password** on the updated Flipper app. An ordinary device save preserves its existing cost.
- Install runtime and PyInstaller dependencies from the hash-pinned `requirements.lock`. Install uFBT separately from `requirements-build.txt`.
- Package only FAPs rebuilt from this source for Momentum 012 (API 87.1) and Official 1.5.1 (API 88.2).

## Release gates

- Momentum 012 master-password unlock: maintainer-reported about 43 seconds with 350 entries, then about 3 seconds to a usable list.
- Momentum Quick PIN unlock: effectively instant, as reported by the maintainer.
- Official-firmware progress visibility: pending physical confirmation.
- Windows installer and macOS DMG: native build and packaged-app smoke tests passed; interactive USB/BLE testing remains pending.
- Security policy, documented limitations, directory permissions and CI checks are implemented on `hardening`.

## Source-package verification

The Windows Python source ZIP was built and checked from a clean extraction on Linux with `start.py --setup` and `start.py --check`. Its hash-pinned runtime lock excludes uFBT and its SDK-only dependencies. This does not validate the native Windows installer or Windows launcher.

## Unlock timing and compatibility status

Momentum 012 with 350 entries: maintainer-reported master-password unlock about 43 seconds, then about 3 seconds to a usable list; Quick PIN effectively instant. No three-run median is claimed. Derivation displays percentage feedback; Quick PIN unwraps a device-bound key without repeating PBKDF2. Official screen visibility and the full interactive transition remain manual checks.
